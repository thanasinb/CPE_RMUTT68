# 04-620-401 โครงงานวิศวกรรมคอมพิวเตอร์
## Computer Engineering Project | 3(1-6)

**ประเภท:** กลุ่มวิชาบังคับ | **ชั้นปี:** 4 | **ภาคการศึกษา:** 2

**วิชาบังคับก่อน | Prerequisites:** [04-620-303 การเตรียมโครงงานวิศวกรรมคอมพิวเตอร์ (Computer Engineering Pre-Project)](04_620_303_Computer_Engineering_Pre-Project.md)

---

## คำอธิบายรายวิชา | Course Description

การทำโครงงานหรืองานวิจัยที่ได้รับอนุมัติ การรายงานความคืบหน้า การนำเสนอผลการดำเนินงาน การจัดทำรายงานโครงงานวิศวกรรมคอมพิวเตอร์ฉบับสมบูรณ์หรือบทความทางวิชาการหรือวารสารทางวิชาการ / Implementation of improved project; progress report; project examination; presentation of completed project; submitting Computer Engineering project report or academic proceeding or academic journal

## ผลลัพธ์การเรียนรู้ระดับหลักสูตร (PLOs) ที่รายวิชารับผิดชอบ

| [PLO3](../../CPE_RMUTT68_Prospectus.md#plo3): บูรณาการความรู้ในสาขาวิศวกรรมคอมพิวเตอร์เพื่อแก้ไขปัญหาให้กับอุตสาหกรรมหรือชุมชน เพื่อการพัฒนาที่ยั่งยืน | ✓ |  |  |  |
| [PLO4.1](../../CPE_RMUTT68_Prospectus.md#plo4-1): ระบุ กำหนด และวิเคราะห์ปัญหาทางวิศวกรรมคอมพิวเตอร์อย่างเป็นระบบ โดยค้นคว้าข้อมูลที่เกี่ยวข้อง เพื่อหาแนวทางแก้ไขเบื้องต้นได้ |  | ✓ |  |  |
| [PLO5](../../CPE_RMUTT68_Prospectus.md#plo5): ใช้เครื่องมือทางด้านวิศวกรรมคอมพิวเตอร์ได้อย่างถูกต้องเหมาะสม |  | ✓ |  |  |
| [PLO6](../../CPE_RMUTT68_Prospectus.md#plo6): อธิบายจรรยาบรรณวิชาชีพได้ มีความตรงต่อเวลา |  |  | ✓ |  |
| [PLO7](../../CPE_RMUTT68_Prospectus.md#plo7): อธิบายและประยุกต์ใช้เทคโนโลยีทางวิศวกรรมคอมพิวเตอร์ที่ไม่เคยเรียนในหลักสูตรได้ |  |  |  | ✓ |
| [PLO8.1](../../CPE_RMUTT68_Prospectus.md#plo8-1): ทำงานเป็นทีมร่วมกับผู้อื่นที่มีความหลากหลายได้อย่างมีประสิทธิภาพ |  |  |  | ✓ |
| [PLO8.2](../../CPE_RMUTT68_Prospectus.md#plo8-2): สื่อสารความคืบหน้าและปัญหาได้ตรงประเด็นทั้งภาษาไทยและภาษาอังกฤษ และเสนอแนวทางแก้ไขพร้อมเหตุผลรองรับได้ |  |  |  | ✓ |
